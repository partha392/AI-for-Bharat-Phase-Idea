# 🎬 1-Minute Demo Script

## The Killer Demo Path

**Scenario**: Rural farmer in Uttar Pradesh wants to know about agriculture schemes

### Step 1: Launch (10 seconds)
```bash
python run_gui.py
# Opens http://localhost:8501
```

### Step 2: Navigate to Voice Chat (10 seconds)
- Click "🔊 आवाज़ी चैट" in sidebar
- Click "🎤 आवाज़ी चैट शुरू करें" (Start Voice Chat)

### Step 3: Demo Voice Command (20 seconds)
- Click demo button: "🎙️ मुझे कृषि योजनाओं के बारे में बताएं"
- System processes in Hindi
- AI responds with PM-KISAN details in Hindi

### Step 4: Show Scheme Discovery (15 seconds)
- Click "🎯 योजना खोज" in sidebar
- Search "agriculture" 
- See matching schemes with eligibility

### Step 5: Language Switch Demo (5 seconds)
- Change language to English in sidebar
- UI instantly updates to English
